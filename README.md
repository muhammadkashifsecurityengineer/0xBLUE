# 0xBLUE: SOC Analyst Arsenal

Author: [Muhammad Kashif | GitHub](https://github.com/muhammadkashifsecurityengineer)

A curated, browser-importable bookmark collection covering SOC Analysis, Incident Response, DFIR, Threat Hunting, and Threat Intelligence.

453 links across 61 categories, spanning reference material, attack techniques, log schemas, blue team tooling, sample datasets, training, and community resources. Categories and links are sorted alphabetically throughout.

## Why this exists

Most "awesome list" repositories for security are plain Markdown, which means copying and pasting links one at a time. This repository ships the collection as a standard Netscape bookmark file (`bookmarks.html`), so it imports directly into Chrome, Firefox, Edge, or Brave as a ready-made bookmark folder structure, in addition to being browsable here on GitHub.

## Import instructions

**Chrome / Edge / Brave**
1. Open Bookmark Manager (`Ctrl+Shift+O` / `Cmd+Shift+O`).
2. Click the three-dot menu, select **Import Bookmarks**.
3. Choose `bookmarks.html` from this repository.

**Firefox**
1. Open the Library (`Ctrl+Shift+O` / `Cmd+Shift+O`).
2. **Import and Backup > Import Bookmarks from HTML**.
3. Select `bookmarks.html`.

## Scope and maintenance notes

- Every link is verified reachable and current as of the last update. Tools that have been shut down or superseded (for example, the original `dnSpy` project or `CRXcavator`) are replaced with their actively maintained successors rather than left as dead links.
- The collection favors free and community-accessible resources over vendor-gated platforms, so it stays usable without enterprise licensing.
- Categories are sorted alphabetically, and links within each category are sorted alphabetically, so new pull requests should slot into the correct position rather than being appended to the end.
- Pull requests are welcome. When proposing an addition, note which category it belongs in and confirm the resource is still actively maintained.
